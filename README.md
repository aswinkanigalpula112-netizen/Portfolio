# Aswin Kanigalpula — Portfolio

Personal portfolio built with Next.js 16, Tailwind CSS v4 and Motion. Live at https://aswin-portfolio-sable.vercel.app

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

All text lives in `src/lib/data.ts` (name, role, tagline, email, socials, projects, experience).
Project videos, posters and screenshots are in `public/projects/`.

## Deploy

```bash
npm run build
vercel deploy --prod
```
